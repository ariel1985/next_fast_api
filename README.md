# Simple Video Upload Web App

This project has:
- **frontend** (Next.js)
- **backend** (FastAPI)
- **data** (for uploaded videos)

## Setup

1. Clone or download this repo.
2. Install dependencies for both frontend and backend.
3. Run the backend (FastAPI).
4. Run the frontend (Next.js).
5. Upload a video file via the web form.
6. The uploaded file will appear in the `data` folder.
